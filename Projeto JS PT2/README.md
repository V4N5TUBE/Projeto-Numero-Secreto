# 🎯 Jogo do Número Secreto

Projeto desenvolvido em **JavaScript** com o objetivo de praticar conceitos básicos de lógica de programação e manipulação de elementos HTML.

O jogo gera um número secreto aleatório entre **1 e 10**, e o jogador deve tentar descobrir qual número foi sorteado.

## 🚀 Como funciona

O jogador digita um número no campo disponível e realiza uma tentativa.

O programa verifica o valor informado e apresenta uma das seguintes mensagens:

* **"O número é maior"** caso o número secreto seja maior que o chute.
* **"O número é menor"** caso o número secreto seja menor que o chute.
* **"Acertou"** quando o jogador encontra o número secreto.

Ao acertar, o programa também informa quantas tentativas foram necessárias.

Depois disso, o botão **Novo jogo** é habilitado para iniciar outra partida.

## 🧠 Principais funcionalidades

* Geração de números aleatórios.
* Controle da quantidade de tentativas.
* Números sorteados não se repetem até que todas as possibilidades sejam utilizadas.
* Manipulação de elementos HTML através do JavaScript.
* Limpeza automática do campo após uma tentativa.
* Foco automático no campo de entrada.
* Botão para reiniciar a partida.
* Leitura das mensagens em voz alta utilizando ResponsiveVoice.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
4. Escolha um número e tente descobrir o número secreto.
