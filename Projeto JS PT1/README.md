# 🔢 Jogo do Número Secreto

Projeto simples desenvolvido em **JavaScript** para praticar os fundamentos da lógica de programação.

O programa gera um número secreto aleatório entre **1 e 5000**, e o jogador precisa descobrir o número utilizando as dicas fornecidas pelo jogo.

## 🚀 Como funciona

Ao iniciar o programa, uma mensagem de boas-vindas é exibida.

O JavaScript gera um número secreto aleatório entre **1 e 5000**.

O jogador informa seus palpites através do `prompt()`.

A cada tentativa, o programa verifica o valor informado:

* Se o chute for **maior** que o número secreto, o jogo informa que o número procurado é menor.
* Se o chute for **menor**, o jogo informa que o número procurado é maior.
* Se o jogador **acertar**, o jogo é encerrado.

Ao final, uma mensagem mostra o número secreto e a quantidade de tentativas utilizadas.

## 🧠 Principais funcionalidades

* Geração de número aleatório.
* Entrada de dados utilizando `prompt()`.
* Exibição de mensagens utilizando `alert()`.
* Comparação entre o chute e o número secreto.
* Contagem automática de tentativas.
* Uso correto de "tentativa" ou "tentativas" na mensagem final.

## 🛠️ Tecnologia utilizada

* JavaScript

O projeto utiliza conceitos fundamentais de JavaScript, como:

* Variáveis
* `let`
* Estrutura de repetição `while`
* Condicionais `if` e `else`
* Operadores de comparação
* Operador ternário
* Incremento (`++`)
* `Math.random()`
* `parseInt()`
* Template strings
* `alert()`

## ▶️ Como executar

O código deve ser executado em um ambiente que permita o uso de `alert()` e `prompt()`, como um navegador.

1. Abra o projeto no navegador.
2. Aguarde a mensagem de boas-vindas.
3. Digite um número entre **1 e 5000**.
4. Utilize as dicas para chegar ao número secreto.
5. Continue tentando até acertar.

## 🎯 Objetivo do projeto

O objetivo deste projeto é praticar os **fundamentos da lógica de programação em JavaScript**, especialmente estruturas condicionais, loops, variáveis e geração de números aleatórios.
